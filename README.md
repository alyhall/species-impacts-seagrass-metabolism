
# Benthic metabolism of Chesapeake Bay seagrasses

This dataset contains environmental variables, seagrass biomass metrics, and calculated benthic metabolism metrics for seagrass meadows (Zostera marina & Ruppia maritima) at sites in the lower Chesapeake Bay, Virginia. The data consist of four .csv files:

1) Seagrass_Metabolism_Dataframe.csv (individual chamber metabolic fluxes with all paired biotic and abiotic data for that incubation),

2) Metabolic_Contributions_From_Epiphtyes_Data.csv (individual chamber metabolic fluxes with estimated seagrass and epiphyte contributions)
   
3) Site_Seagrass_Metabolism.csv (Site/date level averages for higher level metabolic rates [GPP, R, P:R, etc])
   
4) Metadata_Key.csv (Key for column names, units, and meaning for datafiles)
   
5) MS_Code.R (R code for more complex data analysis [e.g. model comparison and sclaing up])

These data support findings that seagrass species identity affects whole system metabolism.
